# Arsip V1 — jangan gunakan untuk mengklaim eksekusi V2

`seed_rkg_spm.cypher` adalah skrip seed **versi anotasi awal** yang berasal dari sumber penelitian terdahulu. Versi ini **bukan** padanan teruji dari graf NetworkX V2. Jalankan hanya di basis data uji kosong yang terpisah, bila perlu memeriksa historis; jangan menggabungkan dengan dataset V2/V3.

Paket V2 sebelumnya menyebut `seed_neo4j_v2.cypher`, tetapi berkas tersebut belum berhasil dipulihkan dari ZIP asli pada sesi ini.
